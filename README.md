# Hybrid DQN：使用 GA 缓解 DQN 早期冷启动问题  
# Hybrid DQN: Using GA to Mitigate the Early Cold-Start Problem in DQN

## 1. 项目目标 / Project Objective

本项目通过对比 **Baseline DQN** 和 **Hybrid DQN（GA + DQN）** 在智能体避障到达目标过程中的训练表现与评估表现，判断混合 GA 的 DQN 强化学习方法是否可以缓解传统纯 DQN 在训练早期的 **cold start（冷启动）困境**。

This project compares the training and evaluation performance of **Baseline DQN** and **Hybrid DQN (GA + DQN)** in an obstacle-avoidance navigation task. The goal is to determine whether the GA-assisted DQN reinforcement learning method can mitigate the **cold-start problem** commonly observed in standard DQN during the early training stage.

核心问题是：

The core research question is:

> 使用 GA 生成的启发式控制器参数预先填充 DQN 的 replay buffer，是否能够减少早期无效碰撞经验，从而提高 DQN 的训练稳定性与样本效率？
>
> Can heuristic controller parameters generated by GA be used to pre-fill the DQN replay buffer, thereby reducing ineffective early collision experiences and improving the training stability and sample efficiency of DQN?

---

## 2. 为什么要解决冷启动问题？ / Why Solve the Cold-Start Problem?

### 2.1 冷启动困境的影响 / Impact of the Cold-Start Problem

DQN 在训练初期依赖 replay buffer 中的数据进行学习。如果前期大部分 episode 都是如下失败轨迹：

In the early training stage, DQN learns from the data stored in the replay buffer. If most early episodes are failed trajectories such as:

```text
状态 -> 随机动作 -> 很快碰撞 -> 负奖励
State -> Random action -> Quick collision -> Negative reward
```

那么 replay buffer 会被大量失败经验占据。此时网络学到的主要不是“如何到达目标”，而是大量短程失败轨迹。

Then the replay buffer will be dominated by failed experiences. In this case, the network mainly learns many short failure trajectories rather than learning how to reach the target.

在导航任务中，成功奖励通常是稀疏的。例如，只有智能体到达目标点时才会获得较大的正奖励。如果经验池中的成功样本过少，那么 DQN 在早期几乎看不到成功轨迹，自然也难以学习到“哪些状态-动作序列最终能够成功”。

In navigation tasks, success rewards are usually sparse. For example, the agent may only receive a large positive reward when it reaches the target. If there are too few successful samples in the replay buffer, DQN can hardly observe successful trajectories in the early stage. Therefore, it becomes difficult for the model to learn which state-action sequences can eventually lead to success.

这会带来以下问题：

This causes the following problems:

- 降低训练效率；  
  Reduced training efficiency;
- 延缓模型收敛速度；  
  Slower model convergence;
- 使 Q 值更新长期被负奖励主导；  
  Q-value updates are dominated by negative rewards for a long time;
- 使模型容易形成保守或错误策略，例如一直转圈、卡在某种动作偏好，或者学不到稳定的避障行为。  
  The model may develop conservative or incorrect policies, such as repeatedly turning in circles, being stuck in a biased action preference, or failing to learn stable obstacle-avoidance behavior.

---

## 3. 解决思路 / Proposed Solution

本项目使用 **GA（Genetic Algorithm，遗传算法）** 对低维启发式控制器参数进行搜索。其目标是找到一组较优的控制器参数，使智能体在一个生命周期内生成的动作轨迹能够获得尽可能高的 reward。

This project uses a **GA (Genetic Algorithm)** to search for low-dimensional heuristic controller parameters. The objective is to find a relatively good set of controller parameters so that the trajectory generated by the agent within an episode can obtain as high a reward as possible.

换句话说，GA 不是直接训练神经网络，而是先搜索一组能够产生较好行为的启发式控制器参数。然后使用这组参数控制智能体运行，并将生成的 transition 存入 DQN 的 replay buffer 中。

In other words, GA does not directly train the neural network. Instead, it first searches for a set of heuristic controller parameters that can generate better behavior. These parameters are then used to control the agent, and the generated transitions are stored in the DQN replay buffer.

这样可以用 GA 产生的较高质量轨迹替代纯 DQN 早期的随机探索轨迹，从而缓解冷启动问题。

This allows the higher-quality trajectories generated by GA to replace the random exploration trajectories used by standard DQN in the early stage, thereby mitigating the cold-start problem.

---

### 3.1 GA 启发式控制器参数 / GA Heuristic Controller Parameters

GA 搜索得到的参数向量用于控制智能体如何在目标吸引和障碍物避让之间进行权衡。

The parameter vector found by GA controls how the agent balances target attraction and obstacle avoidance.

| 参数 / Parameter | 名称 / Name | 含义 / Meaning |
|---|---|---|
| `params[0]` | `w_target` | 目标方向权重。控制智能体朝目标方向进行偏航角修正。<br>Target-direction weight. It controls how strongly the agent corrects its yaw angle toward the target. |
| `params[1]` | `w_side` | 左右障碍物危险差异权重。当 `left_danger > right_danger` 时，说明左侧更危险，智能体应倾向向右转。<br>Left-right obstacle danger difference weight. When `left_danger > right_danger`, the left side is more dangerous, so the agent should tend to turn right. |
| `params[2]` | `w_front` | 正前方危险权重。当前方射线距离很短时，增强避障行为。<br>Front danger weight. When the front ray distance is very short, the obstacle-avoidance behavior is strengthened. |
| `params[3]` | `w_front_group` | 前方一组射线危险权重。不只看正中间一根 ray，而是观察 `rays[4:7]` 的局部危险情况。<br>Front-ray group danger weight. Instead of only considering the middle ray, it observes the local danger represented by `rays[4:7]`. |
| `params[4]` | `bias` | 转向偏置。<br>Steering bias. |
| `params[5]` | `threshold_small` | 小转向阈值。<br>Small steering threshold. |
| `params[6]` | `threshold_large` | 大转向阈值。<br>Large steering threshold. |

### 3.2 使用 GA 控制器参数填充 DQN Replay Buffer / Filling the DQN Replay Buffer with GA Controller Parameters


GA 得到 `best_params` 后，将该参数组放入环境中控制智能体行动。每一步产生的经验都会被存入 DQN 的 replay buffer。

After GA obtains `best_params`, this parameter set is placed into the environment to control the agent's behavior. The experience generated at each step is stored in the DQN replay buffer.

整体流程如下：

The overall process is as follows:

```text
GA 得到 best_params
GA obtains best_params
        ↓
每一步读取当前 state
Read the current state at each step
        ↓
heuristic_action(state, best_params) 计算动作
heuristic_action(state, best_params) computes the action
        ↓
环境执行动作
The environment executes the action
        ↓
得到 reward、next_state、done
Obtain reward, next_state, and done
        ↓
把这一步 transition 存入 replay buffer
Store this transition in the replay buffer
        ↓
如果 done，就 reset 环境，开始下一条轨迹
If done, reset the environment and start the next trajectory
```

其中，单步经验可以表示为：

A single-step experience can be represented as:

```text
transition = (state, action, reward, next_state, done)
```

通过这个流程，Hybrid DQN 用 GA 生成的启发式轨迹替代纯 DQN 前期对 replay buffer 的随机填充策略。这样可以提升 replay buffer 的前期样本质量，从而提升训练效率并加快模型收敛。

Through this process, Hybrid DQN replaces the random replay-buffer filling strategy used by standard DQN in the early stage with heuristic trajectories generated by GA. This improves the early sample quality of the replay buffer, thereby improving training efficiency and accelerating model convergence.

---

>
> GA pre-training or GA-based experience filling does not necessarily significantly improve the upper bound of the final model performance, but it can effectively improve the early training quality of DQN. It is especially suitable for mitigating the cold-start problem in reinforcement learning navigation tasks.
